# 🧬 Gene Expression Analyzer

A Python-based bioinformatics tool for analyzing gene expression datasets.  
This project demonstrates skills in data cleaning, statistical analysis, and visualization using real biological data.

---

## 🚀 Features

- Load gene expression datasets (CSV format)
- Perform data cleaning and preprocessing
- Compute mean gene expression across samples
- Identify top highly expressed genes
- Visualize results using bar plots
- Export results to CSV

---

## 🛠️ Technologies Used

- Python
- pandas
- numpy
- matplotlib

---

## 📊 Dataset Format

Input CSV file should follow this structure:

Gene,Sample1,Sample2,Sample3  
GeneA,10,12,9  
GeneB,50,45,60  
GeneC,5,7,6  

- First column: Gene names  
- Remaining columns: Expression values
